# Attention Model

Autonomy levels are transparent operational descriptions:

| Level | Meaning                                                           |
| ----- | ----------------------------------------------------------------- |
| 0     | Informational only                                                |
| 1     | Recommends actions                                                |
| 2     | Drafts/prepares actions for human approval                        |
| 3     | Performs bounded actions with explicit controls                   |
| 4     | Performs material actions with limited supervision                |
| 5     | Operates broadly and may delegate or create consequential effects |

Autonomy is not the score. The deterministic 0–100 attention score sums capped contributions for autonomy, financial authority, contractual authority, external communication, data sensitivity, operational impact, human oversight, reversibility, sub-agent delegation, document clarity, insurance ambiguity, missing documents, and pack maturity.

Stronger pre-action oversight reduces its component. Missing documents increase attention and lower confidence. GLOBAL fallback lowers confidence instead of inventing localized conclusions. Outputs show every point contribution and explanation. Labels prioritize review; they are not actuarial, legal-risk, loss, enforceability, or coverage probabilities.
